# 统一重叠展示：跨周角标与本周分段轮廓

状态：产品方向已确认；书面设计待用户审阅；未开始实施计划或生产实现。

代码基线：`1b66e5f073065536e1fbce64736586faf5959ba1`。

## 1. 与既有验收的关系

这是 J2 实体设备验收期间提出的新需求，不是 UI-R4 已接受实现的回归缺陷。
此前 SCHOOL-only 聚合、MANUAL 隔离和纯 ghost 并排是批准过的行为；本设计仅替代这些展示限制。
J2/J3 尚未完成，不标记 PASS。新行为实现后须针对最终代码树继续资格验证，不能把旧截图或旧测试冒充新行为证据。

截至本设计，真实同步前后全部三个手动项完整记录相同，学校数据仍为十一门课程、十九条安排；用户报告没有更新提示。这些是此前基线的观察，不是本设计的实施成果。

## 2. 已确认的产品规则

- 不同周的学校课程和手动项不得把当前卡片挤成细条，统一使用右下角矢量标记。
- 本周真实同时发生的事件允许分割；只分割重叠的时间段，独占时间段占满可用列宽。
- 完全同起止时间的本周事件默认并排；设置允许改为优先较早添加的代表项，其余进入本周冲突标记。
- 本周无内容时，用最早出现周的灰度代表卡承载跨周候选，不再把多个 ghost 挤在一起。
- 详情首项始终是点击的代表内容，随后才是其他内容；手动项保留编辑入口。
- 同一学校课程的教师、地点等变体仍在单页完整安排中呈现；仅周次不同不创建变体标记。
- 名称、地点优先，标记不能遮盖文字；纵向时间映射不变。

## 3. 方案选择与边界

采用统一的、只读的展示投影，再交给布局和详情渲染。它覆盖 SCHOOL、MANUAL 及混合关系，但不改变数据归属。
不采用在现有学校角标旁另加一套手动角标特判的方式，以免两个系统对混合冲突作出不同决定。
也不合并数据库记录：代表卡只是显示入口，隐藏的记录仍独立存在。

保持 Room schema、课程业务身份、手动项持久化、Portal/parser/session、同步指纹、Worker 和导入事务不变。
不修改 `SegmentedTimelineAxis`、`TimeBoundaryMark`、`LongPressResolver`，不重写 WeekOverview 的 active-only 纵向投影。
“所有页面”指所有学期/周的主课表展示使用相同规则，不让周缩略图引入其他周 ghost。

## 4. 身份与排序

展示身份使用带类型的键：学校为学期范围内的稳定课程业务身份，手动项为现有 ManualItemId。不能用显示名称合并。
同名不同课程号、两个同名手动项仍是不同内容。学校本地 MeetingId 只能查找记录，不参与代表选择或排序。

较早添加的排序键：

1. MANUAL 使用真实 `createdAt`；SCHOOL 使用所属学期 `importedAt`。
2. 时间相同时，用类型限定的稳定身份字典序破同分。
3. 同一学校身份有多个安排时，用规范化 presentation key 破同分：weekday、start、end、location、排序去重的教师列表、规范周次集合。

学校没有每门课的首次导入时间，也没有选课时间。本设计明确不伪造这些数据；后续同步加入的学校课程仍按所属学期导入时间排序。
设置解释文案必须说明这个限制。编辑手动项不改变其创建顺序。

## 5. 跨周聚合

只在 `showNonCurrentWeek=true` 时处理其他周候选；关闭时不显示 ghost 或跨周标记。
同一天以正的时间交集判断重叠：`max(startA,startB) < min(endA,endB)`。首尾相接不算冲突。

先分离当前查看周 active 和其他周 ghost。ghost 不参与 active 的宽度分配。
ghost 与一个或多个 active 重叠时，附着到交集分钟数最大的 active；同分按稳定规范键排序，输入顺序不影响输出。
每个 ghost 只附着一次。代表卡的时间范围保持自身实际起止，不因候选范围更长而扩大；候选完整起止在详情中展示。

未附着的 ghost 按最早出现周、较早添加排序键、规范安排键排序。依次取第一项为灰度代表，收纳与它直接正交集的剩余候选，然后重复处理尚未收纳者。
不把 A 与 B、B 与 C 的传递关系当成 A 与 C 直接重叠；不画出覆盖空档的虚假整块。
灰度代表之间若仍有真实时间交集，按分段轮廓布局处理，不回退到全高窄条；其他候选仍只在标记详情中显示。

## 6. 本周部分重叠：分段轮廓

布局输入为展示投影保留的代表块。按 weekday 分组，使用各块起止时刻作为分段边界。
每一段只考虑该段内实际存在的块；一个块独占时占满该日列宽，多个块存在时分配互不重叠的水平区间。
二者示例必须严格满足：

| 时间段 | A：10–12 | B：11–13 |
| --- | --- | --- |
| 10–11 | 全宽 | 不显示 |
| 11–12 | 左半 | 右半 |
| 12–13 | 不显示 | 全宽 |

以稳定键确定左右顺序，同一冲突范围中尽量保留连续块的左右关系。
每个事件的实际占用矩形组成同一可点击轮廓，而不是多张重复课程卡；片段边界不产生额外的横向分隔线或重复圆角。
三个及以上事件也必须满足每段无重叠绘制、独占全宽、无时间外延、输入置换不变。复杂阶梯形允许有多个内容片段，但不允许借外接矩形覆盖其他事件。

所有片段的 Y 位置继续调用既有时间轴。已有视觉内缩只作用于外轮廓，内部拼接不能产生人为时间空隙。
文字放在该事件内部能容纳内容的连续矩形区域，优先最大可读面积，同分选更靠上、再靠左的区域。
一张逻辑卡只排一次正文；优先级保持名称 > 地点 > 教师 > 时间。地点继续支持换行，不回退为固定单行截断。
可用空间不足时沿用现有文本预算降级，详情与无障碍描述保留完整字段。

## 7. 完全重叠偏好

新增一个 SettingsStore 展示偏好：`exact_overlap_display_mode`，字符串枚举 `SPLIT` / `EARLIEST`。
缺失或未知值回退 `SPLIT`，不创建 Room migration，不改变任何现有 key。
设置为单选，确认选择后持久化；退出选择界面而未选值不改变偏好。

完全重叠严格指同 weekday、相同 start、相同 end。包含关系或部分交集不受此偏好隐藏。
`SPLIT`：组内所有本周不同事件并排；仍参与外部其他事件的分段布局。
`EARLIEST`：按第 4 节选择代表，隐藏的完全重叠项进入独立“本周冲突”标记。其代表再与其他非完全重叠 active 进行分段布局。
跨周候选不会取代本周代表。该偏好不改变灰度代表的最早周选择规则。

设置文字：完全重叠内容；选项“并排显示（默认）”“优先较早添加”；说明“手动事项按创建时间；学校课程按学期导入时间，同批按稳定课程标识排序”。

## 8. 标记、详情与编辑

保留三种可辨认的矢量语义：跨周不同内容（叠层）、同课程安排变体（空心圆）、本周完全冲突（分叉）。不使用 Unicode 字符充当图标。
相同类型只显示一个标记，不按候选数量堆叠。标记区在代表轮廓内右下方的可用区域，正文测量预留其区域，不覆盖地点。
极小卡无法容纳独立标记时，整卡点击仍可进入完整候选详情，无障碍描述须声明候选种类和数量。

点跨周标记：当前代表为第一页，附着的不同身份内容为后续页。
点本周冲突标记：当前代表为第一页，被隐藏的本周完全重叠项为后续页。
两种列表不把本周冲突伪装成其他周内容。点同课程变体标记仍打开单页完整安排。
学校内容每个稳定身份仅一页，手动内容每个 ManualItemId 仅一页；同一学校身份内所有相关安排集中到完整安排。
替代页确定性排序沿用第 4 节，学校 anchor 优先该查看周安排，否则最早出现周，再用规范安排键。

普通手动卡正文点击保持进入现有编辑器；其标记点击进入候选详情，手动详情提供明确的“编辑此事项”入口，并以该页原 ManualItemId 打开编辑器。
保存只修改该手动项，不修改代表项或其他候选；返回后从最新数据重新投影。
已删除的候选不能使用列表下标误编辑其他项，应移除对应详情页；无剩余候选时关闭详情。

点击命中基于实际片段，不用整块外接矩形。标记点击不同时触发卡片点击。
保留现有横向切周、纵向概览、长按及超 slop 后取消 click 的仲裁。长按是否为空白仍按当前实际可见片段判定；坐标 authority 仍是七列网格。

## 9. 组件职责与接入位置

现有 `SchoolGhostProjection.kt` 的学校专属输入扩展为独立的 typed 展示投影，不让 UI 查询数据库。
`TimetableViewModel` 提供学校/手动块及已有学期导入时间、手动创建时间；投影输出代表、候选、标记语义。
`WeeklyTimetableLayout.kt` 旁的纯布局组件生成时间分段和水平片段。
`WeeklyTimetableGrid.kt` 负责片段轮廓、文字区域、标记及命中，不改变业务时间。
`CourseDetailPager.kt` / `TimetableScreen.kt` 的展示模型增加手动详情分支，学校完整安排继续复用既有模型。
`SettingsStore.kt`、`SettingsViewModel.kt`、`SettingsScreen.kt` 只增加上述完全重叠偏好接线。

## 10. 验证要求

纯投影测试覆盖 SCHOOL/SCHOOL、SCHOOL/MANUAL、MANUAL/MANUAL；active/ghost、ghost-only；同名不同身份；周次单独变化；传递重叠；输入置换及本地 MeetingId 更换。
纯布局测试验证二事件 10–12/11–13 三段精确宽度、首尾相接、嵌套、三项重叠、完全重叠两种偏好、同分稳定顺序、片段不超逻辑时间边界。
排序测试验证学校使用学期 importedAt、手动编辑不改变 createdAt、设置未知值回退 SPLIT、切周/重组不随机换代表。
Compose 测试验证正文不重复、不跨片段遮挡、标记不盖地点、手动候选编辑正确 ID、详情第一页为代表、同课程变体不分页、删除候选后无过期编辑。
手势回归覆盖实际片段命中、空白长按、标记/正文事件隔离、纵向展开与横向 Pager。
设备视觉覆盖 LIGHT/DARK、fontScale 1.0/1.3、概览展开/收起；21:55、七天、固定 rail 和既有纵轴回归必须保持。
真实同步前后手动项不变仍是独立业务验收，不能用展示测试替代。

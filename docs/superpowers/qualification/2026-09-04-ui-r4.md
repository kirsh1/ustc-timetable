## Root-cause record

- The time gutter lived inside each `HorizontalPager` page, so it participated in week swipes.
- teaching-group detection used a 20-minute boundary while compression used a greater-than-30-minute boundary.
- the gutter's grouped rendering omitted individual period boundaries.
- logical course bounds and painted card bounds were identical, obscuring adjacent grid lines.
- the top bar placed its weighted spacer before the next arrow and used different containers for week and date.
- the outer theme was fixed to light; a background `Box` did not provide `onSurface`, leaving inherited controls dark in dark mode.

## Behavioral evidence

- `FixedTimeRail` is a sibling before `HorizontalPager`; weekday/date headers and grid remain within each pager page.
- the official four teaching-group gaps resolve to the same requested visual height; inverse time mapping continues through the same reversible axis.
- all 13 period starts/ends are represented, including adjacent 5-minute boundaries and `21:55`; custom profile times remain the authority.
- course cards inset their painted rectangle by 1dp without changing their logical interval; text priority is name, location, teacher, time.
- top-bar semantic bounds on the API 36 emulator showed equal 54px visual gaps around the week/date group and matching y=202px text centers.
- LIGHT is the default. LIGHT, DARK, and SYSTEM are persisted through `appearance_mode`.
- wallpaper uses Photo Picker, persists only the returned URI in `timetable_wallpaper_uri`, requests a persistable read grant, applies a theme-specific scrim, and falls back to the solid theme surface if unreadable.
- an androidTest-owned provider verified wallpaper rendering on timetable, absence on Settings, and unreadable-URI fallback without reading the user's gallery.
